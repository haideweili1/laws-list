☁ 团队同步（多人共同编辑）

这是一个多人共同使用的工作空间：所有人打开网页都会自动看到彼此的修改，无需任何账号。
要保存你自己的修改，只需在下面粘贴管理员发给你的同步令牌，点"保存令牌"即可。不需要注册 GitHub，也不需要自己生成令牌。

给管理员（你来做一次）：
在 GitHub 生成一个仅本仓库、可读写 Contents的细粒度令牌（Fine-grained PAT），复制后通过微信 / 邮件发给同事即可。
生成步骤：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；Repository access 选 haideweili1/laws-list，Permissions → Contents → 设为 Read and write。
